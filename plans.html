Plans

A plan is a calendar: a date range, the days you train, and whatever fixtures you have. Everything else in Session Board hangs off it. The two fall 2026 squads ship built in and cannot be edited, but you can copy either one and change the copy, or start from an empty calendar.

Leave a day blank to make it a rest day. Minutes drive the load totals in the planner.

Blocks

Blocks band the plan and group the export. A plan with no blocks still works.

Fixtures

Columns read: Date, Team, Home/Away, Opponent, Location, Field, Kickoff, Notes. Dates can be 12-Sep, 2026-09-12 or 9/12/2026. You can also add games row by row on the plan itself.

Templates

Move a plan between browsers, or hand it to another coach.

A template holds the calendar and, if you choose, the principle sequencing you have set against it. It never carries session content.
